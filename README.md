# Mr. Casino EA (MT5, золото)

Файл: `MrCasino.mq5` — советник MT5 по стратегии Mr. Casino (Flashcards) + свечи и дисциплина из книги «Oddiy savdo kitobi». Только XAUUSD / GOLD, график M5.

## v3.2 — что по умолчанию

| Что | Значение | Параметр |
|---|---|---|
| Сделок в день | 5 (из них COUNTER до 2) | `InpMaxTradesDay`, `InpMaxCounterDay` |
| Тейк | стоп × 2 (RR 1:2) | `InpTPMode = TP_RR`, `InpRR = 2.0` |
| Риск на сделку | 1% = 5% / 5 сделок | `InpRiskMode = RISK_PERCENT`, `InpRiskPercent = 0` |
| Риск в день | до 5% баланса начала дня, потом пауза до завтра | `InpDailyRiskPct = 5.0` |
| Лот меньше минимального | мин. лот, если влезает в остаток дневного риска | `InpMinLotIfFits = true` |
| Слабые подтверждения | весь день: FU класс C, балл −1, отбой E | `InpWeakSignals = true` |
| Стопов подряд до паузы | 3 (0 = выкл) | `InpMaxLossStreak` |
| Стоп | 5–15 пунктов, True Stop за зоной | `InpMinSLPt`, `InpMaxSLPt`, `InpTrueStop` |

## Триггеры входа (в подтверждённой зоне)

- **A** Manipulation Cycle · **B** HCS (x2/x3 — сильный) · **C** Negation · **D** снятие ликвидности
- **F** FU из трёх свечей · **S** пробой предыдущего хая/лоя после касания зоны (книга)
- **K** книга: молот / падающая звезда, поглощение, утренняя / вечерняя звезда, 3 солдата / 3 вороны, повешенный
- **E** отбой от зоны (при слабых подтверждениях) · **DIRECT** BIW + Doji

Doji или волчок на сигнальной свече — ждём свечу (книга). Свеча, которая сняла ликвидность (FU), Doji не считается (стратегия).
